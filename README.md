# 송대현 | DevOps / Infrastructure Engineer

서비스가 안정적으로 동작하는 환경을 설계하고 운영하는 데 관심이 있는 인프라·DevOps 지향 개발자입니다.  
백엔드 구현 경험을 바탕으로 API·데이터 흐름을 이해하며, 배포·모니터링·운영까지 아우르는 완성도 높은 서비스를 만드는 것을 목표로 합니다.

## About Me

- Docker, PM2 등 배포·프로세스 관리 도구를 활용한 서비스 운영 경험이 있습니다.
- Node.js·Express 기반 REST API와 MongoDB 데이터 구조를 이해하고, 이를 안정적으로 운영하는 관점에서 인프라를 고민합니다.
- JWT 인증, Firebase Cloud Messaging, 스케줄링 및 외부 API 연동을 포함한 서비스 전체를 다뤄본 경험이 있습니다.
- 기능 구현에 그치지 않고 배포, 모니터링, 장애 대응 등 운영 관점까지 함께 생각합니다.
