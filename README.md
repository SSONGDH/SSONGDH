# 송대현 | Backend Developer

서비스의 흐름을 이해하고, 안정적인 API와 데이터 구조로 구현하는 백엔드 개발자입니다. 사용자에게 실제로 필요한 기능을 고민하며 팀과 함께 완성도 높은 서비스를 만드는 것을 지향합니다.

## About Me

- Node.js와 Express를 활용한 REST API 설계 및 구현 경험이 있습니다.
- MongoDB와 Mongoose를 기반으로 데이터 모델과 비즈니스 로직을 설계합니다.
- JWT 인증, Firebase Cloud Messaging, 스케줄링 및 외부 API 연동 경험이 있습니다.
- 기능 구현에 그치지 않고 서비스 운영과 사용자 경험까지 함께 고민합니다.
